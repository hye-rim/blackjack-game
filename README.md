# 블랙잭 🃏

칩을 걸고 하는 블랙잭. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 의존성 없는 정적 게임(`index.html` + `logic.js` + `game.js`)입니다. **칩은 게임용이며 실제 돈과 무관합니다.**

- 21에 가깝게 만들되 넘으면(버스트) 진다. 딜러는 17 이상이면 멈춘다(소프트 17도 멈춤). 6덱 슈, 카드가 78장 아래로 줄면 새로 섞는다
- 칩 1,000개로 시작. 5·10·25·100·500 칩을 눌러 판돈을 걸고(한 판 최대 1,000), '같은 금액'으로 지난 판돈을 다시 건다
- 이기면 건 만큼, 비기면 그대로 돌려받고, 블랙잭(처음 두 장이 A+10)은 **3 : 2**
- **히트**(한 장 더) · **스탠드**(멈춤) · **더블**(처음 두 장일 때 판돈 두 배 + 딱 한 장) · **스플릿**(같은 값 두 장을 두 손으로, 한 번만. 에이스는 한 장씩만 받고 21이 나와도 블랙잭으로 치지 않음)
- 판돈을 건 순간 칩이 저장된다(새로고침으로 진 판을 무를 수 없다). 칩이 5개 아래로 떨어지면 파산, 다시 1,000개로 시작. 최고로 모은 칩은 `blackjackBest`, 현재 칩은 `blackjackChips`
- 조작: 화면 탭 / PC는 H 히트 · S 스탠드 · D 더블 · P 스플릿 · 1~5 칩 · C 비우기 · R 같은 금액 · Enter(스페이스) 딜/다음 판 · M 소리

규칙은 `logic.js`(화면 없이 Node 로 시험할 수 있다), 화면·입력·소리는 `game.js`.
